# Examples

- [Basic example](basic.mjs)
- [Custom process-like object](example.mjs)

## Basic example

Prerequisite: Node.js 26 or newer and installed package dependencies.
Run `node examples/basic.mjs` from the repository root.
The example logs a process warning and removes its handler.

## Custom process-like object

Prerequisite: Node.js 26 or newer and installed package dependencies.
Run `node examples/example.mjs` from the repository root.
The example registers and removes handlers on a local process-like object.
